How the Agent Switches Contexts

The AI Agent dynamically switches between strategies based on statistical filters rather than price predictions. The core switching logic relies on the interaction between Bitcoin (BTC) Trend and Asset-Specific Volatility (ATR Ratio):

  • When BTC is Trending Up (EMA20 > EMA50): The agent permits Alpha for assets in trend and Gamma for assets breaking out of compressions.
  • When BTC is Sideways (Range): The agent heavily penalizes directional strategies and activates Beta for range trading. Alpha and Gamma size is halved or disabled.
  • When BTC is Trending Down (EMA20 < EMA50): Alpha and Gamma Longs are strictly forbidden. Beta is allowed only if correlation to BTC is < 0.3.
  • Volatility Filter (ATR): A high ATR(10) relative to history disables Beta (ranges die in high volatility) and enables Alpha/Gamma. A compressed ATR enables Gamma setups.
